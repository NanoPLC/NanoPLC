# and_gate example

Minimal FBD program: two digital inputs ANDed to one digital output. Used for IR compile regression and golden tests.

## Layout

| Path | Purpose |
|------|---------|
| `nanoplc.project.json` | Project marker |
| `src/main.fbd.json` | FBD source (JSON graph until canvas editor ships) |
| `src/io-map.json` | Optional symbolic I/O map |
| `build/ir.json` | Generated by **NanoPLC: Compile PLC program** |

## Try it

1. Open the **`examples/and_gate`** folder as a VS Code workspace (or add it to the monorepo workspace).
2. Command Palette → **NanoPLC: Compile PLC program**.
3. Inspect `build/ir.json`; firmware C is updated at `firmware/components/nanoplc_generated/plc_program.c`.
4. **NanoPLC: Build firmware** (from monorepo root with `nanoplc.firmwareRoot` = `firmware`).

When opened from the monorepo root, set the workspace folder to `examples/and_gate` or run compile with that folder active.

## Expected IR

After compile, `schedule` contains four steps: two `read_di`, one `and`, one `write_do`.

GPIO numbers in `src/io-map.json` (0, 1, 2) are **placeholders** for the example—adjust for your ESP32-S3 board before flashing.
